# Guion didáctico — Recurso Educativo Interactivo
## Tema
Programación Orientada a Objetos.

## Objetivo del recurso
Diseñar un recurso educativo interactivo que facilite la comprensión y aplicación de los fundamentos de la Programación Orientada a Objetos mediante una experiencia gamificada, multimedia y apoyada responsablemente por IA generativa.

## Objetivos de aprendizaje
1. Distinguir clases, objetos, atributos y métodos.
2. Explicar y aplicar abstracción, encapsulación, herencia y polimorfismo.
3. Modelar un problema real mediante clases y relaciones.
4. Implementar clases básicas en Java justificando decisiones de diseño.
5. Utilizar IA para generar ejemplos, prompts y retroalimentación, verificando sus resultados.

## Secuencia
1. Introducción y contextualización: academia de héroes, problema real y propósito.
2. Desarrollo: conceptos POO + ejemplos Java + microvideo.
3. Interactividad: clasificación, detección de errores, modelado y código.
4. Evaluación: retos automáticos + evidencia de producto + lista de cotejo.
5. Retroalimentación: explicación inmediata y recomendaciones.
6. Conclusión: transferencia a GUI y persistencia.

## Multimedia
- Banner principal y banners de unidades proporcionados por el equipo.
- Microvideo local del curso.
- Narración mediante síntesis de voz del navegador.
- Prompts para generación de imágenes.
- Ejemplos de código Java.

## Gamificación
XP, niveles, avatar, insignias, misiones, inventario conceptual, progreso, desbloqueo de unidades, retroalimentación y narrativa.
